# Workspace Rules

- **Inline component page configurations**: Do not write page-specific TSX definitions directly inside page components. Move all docs sections, walkthrough layouts, code snippets, and configuration variables to separate components in `src/components/docs` or separate files.

- **Primary design goal**: Every documentation page must fit within a standard 16:9 laptop viewport (1366×768, 1440×900, 1920×1080) without requiring vertical scrolling. The page should feel like a presentation slide, not a long article. All important information must be visible immediately.
